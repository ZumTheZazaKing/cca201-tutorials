How many processes and threads are running?

Every program you open is at least one process. Inside each process, several threads work at the same time.

Who can be interrupted?

Windows, macOS and Linux are preemptive: they can take the CPU away from a program. But inside one Chrome tab, JavaScript runs one task to the end before the next one starts.

How often does the scheduler switch?

Each time the CPU moves from one thread to another, it is a context switch. Your computer does thousands every second.

Q5 · PCB and TCBQ4 · cost of switching

Do it on your computer

Open PowerShell and run:

Get-Counter '\System\Context Switches/sec' -SampleInterval 1 -MaxSamples 5

On a French Windows the counter name is in French: Get-Counter '\Système\Changements de contexte/s'.

See priorities: Task Manager → Details → right-click a process → Set priority. Only look, do not change it.

# Linux: column "cs" = context switches per second vmstat 1 5 # Mac: column "csw" top -l 2 -s 1 | grep -i "csw"

Think: a switch between two threads of the same process is cheaper than between two processes. Why? (Hint: what do threads share?)

Which jobs use the CPU, which use the disk?

A CPU-bound job calculates a lot. An I/O-bound job mostly waits for the disk, the network or you. A good system keeps both kinds of work going.

Q3a · balancing the mix

Do it on your computer

  1. Open Task Manager → Performance. Keep CPU and Disk (or Ethernet / Wi-Fi) visible.
  2. Copy a big folder to a USB stick, or download a big file: watch which graph goes up.
  3. Now run the busy loop from station 2 in a Chrome tab: watch which graph goes up.
  4. Do both at the same time. Does the copy slow down?

Think: if you only ran CPU-heavy work, what would the disk graph look like? Which manager decides what enters the system?

When fewer programs finish faster

With too many programs for the RAM, the computer spends its time moving pages to and from the disk. Chrome’s Memory Saver puts unused tabs to sleep to stop this.

Q6 · middle-level scheduler

Do it on your computer

  1. In Chrome, open chrome://settings/performance and look at Memory Saver.
  2. Open chrome://discards: the list shows which tabs Chrome can put to sleep or already did.
  3. On Windows, press Win + R, type resmon → Memory tab: watch Hard Faults/sec while you open many heavy apps.
  4. Close half of the apps and watch the number fall.

Think: a sleeping tab still exists, but it is out of memory. Which scheduler does the same thing with jobs? Why do the other tabs feel faster?
