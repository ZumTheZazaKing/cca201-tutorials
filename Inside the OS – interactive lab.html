Inside the OS

Six small experiments to see what the operating system does behind every click. Play first, then explain it in your own words.

Processor Memory File Device

One click, four managers

Helps with tutorial Q1 (saving a report) and Q13 (copying a file)

You only click once. Behind that click, the OS splits the work between four managers, each in charge of one kind of resource.

Pick an action and watch who wakes up, and in what order.

Think: which manager would be busy if two programs wanted the same resource at the same time?

Batch jobs

Helps with tutorial Q2 (monthly payroll)

A studio must turn 20 photos into thumbnails. Run them as one batch, or let a person send them one by one and wait at the screen.

Think: which mode finishes all the work sooner? In which mode does someone have to stay at the screen?

Deadlines

Helps with tutorial Q3 (alarm after the deadline)

Some systems must answer before a deadline (here 100 ms). Raise the system load and see what late answers cost in two different worlds.

Think: the answer was correct every time. Why is that sometimes not enough?

Sharing one CPU

Helps with tutorial Q4 (three apps, one core) and Q12 (multiprogramming)

This computer has a single core. Three programs want it. Run them first one after another, then with time slices, and compare.

Think: in which mode does every program feel alive? Is the core ever running two programs at the same instant?

Memory

Helps with tutorial Q5 (memory almost full)

Each square is a block of RAM. The striped blocks belong to the OS itself.

Launch apps, close them by clicking their blocks, and try to touch the OS area.

Think: why can there be enough free blocks in total and still no room for an app?

Booting up

Helps with tutorial Q6 (starting after power off) and Q14 (boot process)

First, switch the computer off and on and look at what survives in each memory.

Then put the start-up steps in the right order. The check only tells you how many are in place.

Think: if RAM is empty at power-on, where do the very first instructions come from?

    Threads

    Helps with tutorial Q9 (multithreading)

    A gallery app loads 6 photos from the internet. Load it with one thread, then with several, and keep pressing Like while it loads.

    Think: why does the app freeze in one mode? Which other apps do several things at once?

    OS types

    Helps with tutorial Q10 (batch, interactive, real-time)

    Sort these six systems. The check only tells you how many are right.

    Two OSes on one computer

    Helps with tutorial Q11 (more than one OS)

    Two ways to have Windows and Ubuntu on the same laptop. Try switching between them in each setup.
