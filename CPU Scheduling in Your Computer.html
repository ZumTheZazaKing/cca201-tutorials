When does it start? When does it end?

Every web page you open is a small job. Chrome measures for you when the first answer arrives and when everything is finished.

Q1 · response and turnaround

Do it on your computer

  1. Open any website (for example the USM e-learning page). Press F12 → Network tab.
  2. Press Ctrl R to reload. Click the first line of the list (the page itself) → Timing.
  3. Read Waiting for server response: time until the first answer started (like the response time).
  4. At the bottom of the Network tab, read Finish: time until everything was loaded (like the turnaround time).
  5. Type both numbers in the tool on the right.

On a phone: the moment the first text appears vs the moment the loading bar disappears.

Think: the page started to answer quickly but took long to finish. Which measure does a user feel first? Which one counts the whole stay?

Who goes first in your queues?

Your printer queue is FCFS: documents print in the order they were sent. Some download managers let small files go first: that is the shortest job idea.

A deadline every 16.7 ms

To show a smooth video or game at 60 frames per second, each frame must be ready within 16.7 ms. That is a real-time deadline, like in EDF.

Q5 · EDF and missed deadlines

Do it on your computer

  1. Open a YouTube video, right-click it → Stats for nerds. Read Dropped frames.
  2. While it plays, open several heavy programs. Do dropped frames go up?
  3. In Chrome: F12 → Ctrl Shift P → type FPS → Show frame rendering stats.

Think: when frames are dropped, is it because of the order of the work, or because there is simply too much work for the time available?

Foreground first, background later

Operating systems keep several priority levels. The window you use is served first; background work is pushed down. To avoid starvation, Windows gives a priority boost to threads that have waited too long (about 4 seconds): that is aging.

Q6 · multilevel queuesQ6 · starvation and aging

Do it on your computer

  1. Task Manager → Details → right-click a program → Set priority: Realtime, High, Above normal, Normal, Below normal, Low. These are the levels.
  2. Task Manager → Processes: a green leaf means Efficiency mode: Windows moved that background process down.
  3. In Chrome, a hidden tab is also moved down: its timers run at most about once per second. Test it with the tool on the right.

Think: why is it good to push long background work down? What could happen to it if foreground work never stops, and what fixes that?
